# Training Sync: öffentliche Informationsseiten

Statische Projektbeschreibung, Datenschutz und Nutzungshinweise für die OAuth-Konfiguration.

Enthält ausschließlich öffentliche Informationsseiten. Keine FIT-Dateien, Tokens, Passwörter, Datenbanken oder Dienstkonfigurationen hinzufügen.

Geplantes Hosting: GitHub Pages. Vor Veröffentlichung Inhalt und App-Namen prüfen. Nach Veröffentlichung in der Google Search Console eine URL-Präfix-Property für die tatsächliche HTTPS-Adresse einrichten und per HTML-Datei oder HTML-Meta-Tag bestätigen. Den von Google gelieferten Nachweis unverändert einfügen und dauerhaft erhalten.

Google-Branding: Startseite index.html, Datenschutzerklärung datenschutz.html, Nutzungshinweise nutzung.html. URLs und autorisierte Domain erst nach erfolgreicher Veröffentlichung anhand der echten Adresse eintragen. Keine erfundenen URLs verwenden. Googles Akzeptanz muss anschließend geprüft werden.
